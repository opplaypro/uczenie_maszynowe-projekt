# Prostate image segmentation

Semantic (binary) segmentation of prostate images

## Setup & Usage

> [!NOTE]
> This project uses [uv](https://docs.astral.sh/uv/) for fast dependency management and repeatability

1. **Clone this repository**
```bash
git clone https://github.com/opplaypro/uczenie_maszynowe-projekt.git projekt
cd projekt
```

2. **Install dependencies**
```bash
uv sync
```
